# mistral-docs workspace Skill

Answers questions about Mistral products from the documentation, with a link to
the section behind every claim, through the `mistral-docs` connector.

## Add it as a workspace Skill

1. Open `Context` > `Skills` in the sidebar.
2. Click `New Skill`.
3. Fill in the form:
   - **Title**: a short, descriptive name (for example, `Mistral docs`).
   - **Description**: copy the `description` line from `SKILL.md`. This text is
     what Work reads at discovery to decide whether to activate the Skill, so
     keep it specific.
   - **SKILL.md**: copy the body of `SKILL.md`.
4. Click `Create Skill`.
5. From the Skill details page, use the `Share` button to share it with the
   entire workspace.

Workspace admins can **force-enable** the Skill for the whole workspace so every
member answers documentation questions from the documentation.
