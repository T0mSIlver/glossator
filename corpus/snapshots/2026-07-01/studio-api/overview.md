# Studio

[Studio](https://console.mistral.ai) is Mistral's developer platform for AI applications. Use the API to build conversational AI, autonomous agents, document intelligence, and RAG applications. Use the console to manage reusable building blocks, manage keys, test models, and monitor usage.

## Studio capabilities {#studio-capabilities}

Studio gives you programmatic access to Mistral models for text generation, agents, data processing, and more.

- [Core API](https://docs.mistral.ai/studio-api/conversations/chat-completion) — Interact with Mistral models through a unified API for text generation, vision, and structured data extraction.

- [Agent Tools](https://docs.mistral.ai/studio-api/agents/introduction) — Combine language models with built-in tools for multi-step reasoning and autonomous task completion.

- [Document AI](https://docs.mistral.ai/studio-api/document-processing/overview) — Process documents at scale with Mistral OCR, annotations, and structured data extraction.

- [Audio](https://docs.mistral.ai/studio-api/audio) — Transcribe audio and generate speech with Voxtral.

- [RAG & Embeddings](https://docs.mistral.ai/studio-api/knowledge-rag/rag_quickstart) — Build custom retrieval pipelines with embeddings and model generation.

- [Libraries](https://docs.mistral.ai/studio-api/libraries) — Use managed document ingestion and search for built-in RAG.

- [Connectors](https://docs.mistral.ai/studio-api/connectors) — Connect models and Agents to external tools and data sources.

- [Safety & Moderation](https://docs.mistral.ai/studio-api/safety-moderation) — Detect and filter undesirable content in your AI applications with the moderation API.

- [Batch processing](https://docs.mistral.ai/studio-api/batch-processing) — Reduce costs for high-volume asynchronous workloads by up to 50%.

## Getting started with the API {#getting-started-api}

1. **Create an API key** in the console or through the [API keys](https://docs.mistral.ai/admin/identity-access/api-keys) page in Admin.
2. **Send your first request**: follow the [send your first API request](https://docs.mistral.ai/getting-started/quickstarts/developer/first-api-request) quickstart to make a chat completion call in Python or TypeScript.

> **Tip**
>
> If you'd like to explore the features in depth, we suggest starting with the [chat completions](https://docs.mistral.ai/studio-api/conversations/chat-completion) guide and then exploring other features based on your requirements.

## Getting started with the console {#getting-started-console}

Open [Studio](https://console.mistral.ai) and head to the **Playground** to test prompts, compare models, and experiment with parameters: no code needed. From there, you can manage your API keys, review usage, and set up agents.

> **Info**
>
> Some features may vary depending on your plan. Check the [pricing page](https://mistral.ai/pricing) for details.
